## 顺带发现的 Hola 问题（不属于 Wick）

- **Codex 生成的 Excel，Hola 读不出来**：Codex 写的 xlsx 标签带 `x:` 前缀（`<x:row>`），`office.js` 不认，文字版是空的，主脑验收时看不到内容。评测判分器已经兼容；Hola 本身需要修。

## 对 Wick 的启示

1. 第 1 阶段优先：长会话 / 增量消息（S12）、Gemini 改走标准输入（S13）、把"本机环境"（有 Node、没有 Python 等）写进系统提示，减少每轮重新摸索。
2. 第 2 阶段：API 重试、连续出错停止（S14 / S15）。
3. 大部分单人任务四位都已经能做对，完成率的提升空间主要在 S12 / S13；Wick 的收益更多会体现在 **耗时和 token**（门槛：质量分不降）。以后可以再加几道更难的任务。
