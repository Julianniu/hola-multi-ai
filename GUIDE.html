Hola

光辉联合。三束光叠在一起变成白光：Claude、Codex、Gemini 三位队友地位平等、分工不同，你是中间那个点，也就是包工头。

第一次：创建桌面图标

  1. 如果之前的黑色"工地群聊"窗口还开着，先关掉它。
  2. 双击这个文件夹里的 创建桌面图标.bat。
  3. 桌面和开始菜单会出现 Hola 图标。以后双击它就能打开，不会再有黑色窗口。

Hola 在后台安静运行。窗口关掉后，如果 30 分钟内没有活在跑，它会自己退出。想马上退出，可以点左下角"设置"→"退出 Hola"。

怎么派活

  • @ 谁就让谁来：比如"@Codex 把这个表格做成 Excel"。@ 多位时按 @ 的先后顺序依次来。
  • 不点名：参与的队友同时独立作答。只要有人认为值得讨论，他们就会自己多轮讨论，直到都同意，再给你一个团队结论。讨论轮数、结论由谁整理，可以在"设置"里改。
  • 队友之间接力：队友在回复里 @ 别人，就会自动交接。为了防止来回空转，最多自动接力 10 次（设置里可以改）。
  • 随时插话、叫停：干活过程中可以继续发消息；点"叫停"会马上停下这个对话里的所有人。

接入更多 AI，选谁参与

  • 左下角 队友 → 添加队友。有两种接法：
    • API 接入：DeepSeek、通义千问、Kimi、智谱、OpenRouter、本地 Ollama 等 OpenAI 兼容接口。选服务商，填 API Key（模型名以服务商文档为准），点"保存并测试"。API Key 只保存在本机的 data\members.json 里。
    • 命令行：任何有命令行工具的 AI。填命令和参数，参数里写 {PROMPT} 的地方会换成要它做的事。
  • 通过 API 接入的队友不能读写文件、不能联网，只参与思考和写作，老板发的文字类附件会直接附给它看。
  • 输入框下面的 参与：点一下名字，就让这位队友这次不参与（名字会划掉），再点一下恢复。每个对话分开记。不参与的队友不会加入讨论，也不会被队友自动交活；你直接 @ Ta 时仍然会来。

图片和文件

  • 点输入框左边的回形针、直接拖进窗口，或者 Ctrl+V 粘贴截图，都可以添加附件。
  • 队友做出来的文件会直接显示在他的消息下面：图片可以点开放大，其他文件可以打开，或者在文件夹里找到它。

对话和记忆

  • 左侧"新对话"（Ctrl+N）。每个对话都有自己的聊天记录、文件夹和对话记忆，互不干扰。
  • 点右上角"对话记忆"可以查看、修改。队友每次发言前都会先读它，也会把重要结论记进去。
  • 双击左侧的对话标题可以改名。删掉的对话会移到 workspace\.trash，不会被彻底删除。

常见问题

右上角三束光有的暗着
暗着就是那位队友没连上。点一下能看到原因，多半是登录过期：双击 登录Claude.bat 或 登录Gemini.bat 重新登录；Codex 的话在终端里运行一次 codex。弄好后点"重新检查"。
双击图标没反应，或者提示没能启动
双击 START.bat，会出现一个带报错信息的黑色窗口，截图发给 Claude。
想改每个人擅长什么
左下角"设置"，直接改每位队友的"擅长"，大家会按这个分工。
