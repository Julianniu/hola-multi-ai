Hola

光辉联合。三束光叠在一起变成白光：Claude、Codex、Gemini 三位队友地位平等、分工不同，你是中间那个点，也就是包工头。

第一次：安装

  1. 先装好 Node.js（LTS 版）。
  2. 双击 SETUP.bat：它会安装三家的命令行工具，带你依次登录（见下一节），最后在桌面创建 Hola 图标。
  3. 以后双击桌面的 Hola 图标就能打开，不会有黑色窗口。只想重新创建图标的话，双击 Create-Desktop-Icon.bat。

Mac（测试版）：先装好 Node.js，打开"终端"，输入 bash （后面有个空格），把 mac 文件夹里的 SETUP.command 拖进终端窗口，回车。它会安装命令行工具、带你登录，最后生成 Hola 应用，以后在启动台或桌面上点它就行。运行过一次 SETUP 之后，mac 文件夹里的 Login-Claude.command 等文件可以直接双击，作用和下面表格里的 .bat 文件一样。Mac 版还没在真实的 Mac 上完整测试过，有问题欢迎反馈。

重要：命令行队友要先登录

Claude、Codex、Gemini 这三位，以及你自己用"命令行"方式加的队友，都是通过各家的官方命令行工具干活的，用的是你自己的订阅。每一位都必须先在这台电脑上登录一次，否则 Hola 里会显示不在线。SETUP.bat 会带你登录一遍；之后想单独登录或重新登录，用下面的文件：

队友需要的订阅怎么登录
ClaudeClaude Pro / Max双击 Login-Claude.bat，输入 /login，选 Claude account with subscription，在浏览器里授权，然后 /exit。
CodexChatGPT Plus / Pro双击 Login-Codex.bat，选 Sign in with ChatGPT，在浏览器里登录，然后 /exit。
GeminiGoogle AI Pro双击 Login-Gemini.bat（会顺便安装 Antigravity CLI，命令叫 agy），用订阅的 Google 账号登录，然后 /quit。
你自己加的命令行 AI看那家的要求按那家命令行工具的说明，先在终端里登录或配置好 Key，确认它能单独跑通，再加进 Hola。

Claude 一定要选订阅账号登录。如果 Hola 里显示 API Usage Billing，说明走的是 API 按量计费（会另外扣钱），用 Login-Claude.bat 先 /logout 再重新 /login。
Gemini 说明：Google 从 2026 年 6 月起不再让个人订阅使用 Gemini CLI，必须用 Antigravity CLI（agy）。

没有哪家的订阅也没关系，那位队友显示不在线，不影响其他人。通过 API 接入的队友（DeepSeek 等）不需要登录，填 API Key 就行。登录过期时，右上角的光会暗掉，重新登录后点"重新检查"。

怎么派活

  • 不点名：参与的队友同时独立作答。只要有人认为值得讨论，他们就会自己多轮讨论，直到都同意，再给你一个团队结论。讨论轮数、结论由谁整理，可以在"设置"里改。
  • 谈不拢时你来拍板：达成共识的话，队友直接按结论分工开干。讨论到轮数上限还有分歧，结论下面会列出几个方案，写明谁支持哪个；点一个方案，或者直接在输入框里说你的决定（不用 @），队友再按你的决定分工。
  • @ 谁就让谁来：比如"@Codex 把这个表格做成 Excel"。@ 多位时按 @ 的先后顺序依次来。
  • 队友之间接力：队友在回复里 @ 别人，就会自动交接。为了防止来回空转，最多自动接力 10 次（设置里可以改）。
  • 随时插话、叫停：干活过程中可以继续发消息；点"叫停"会马上停下这个对话里的所有人。

接入更多 AI，选谁参与

  • 左下角 队友 → 添加队友。有两种接法：
    • API 接入：DeepSeek、通义千问、Kimi、智谱、OpenRouter、本地 Ollama 等 OpenAI 兼容接口。选服务商，填 API Key（模型名以服务商文档为准），点"保存并测试"。API Key 只保存在本机的 data\members.json 里。
    • 命令行：任何有命令行工具的 AI（记得先登录，见上面）。填命令和参数，参数里写 {PROMPT} 的地方会换成要它做的事。
  • 通过 API 接入的队友不能读写文件、不能联网，只参与思考和写作，你发的文字类附件会直接附给它看。
  • 每位队友擅长什么、用什么颜色，在 队友 里点"编辑"修改，大家会按这个分工。
  • 模型：在 队友 → "编辑" 里可以给 Claude、Codex、Gemini 选模型，比如 Claude 选 Opus 还是 Sonnet，还能选思考深度（想得越深答得越好，但更慢、更费额度）；"默认"就是用它自己的设置。选了订阅里没有的模型会出错，改回"默认"就好。
  • 用量：每条回复下面会写用的模型和用量（输入 / 输出 tokens，鼠标停在上面能看到明细），右上角的队友状态里有本对话每位队友的合计。用订阅时，用量计入订阅额度，不会另外收钱；用 API 时按服务商的价格计费。
  • 权限：默认是安全模式，Claude、Codex 只在对话文件夹里干活，Gemini 只能读不能写。想让某位队友能运行命令、改动电脑上任何地方的文件，在 队友 → "编辑" 里勾上完全权限，队友列表里会标出来。只给你信任的 AI 打开，重要文件记得备份。
  • 输入框下面的 参与：点一下名字，这次就不让 Ta 参与，再点一下恢复。每个对话分开记。你直接 @ Ta 时仍然会来。

图片和文件

  • 点输入框左边的回形针、直接拖进窗口，或者 Ctrl+V 粘贴截图，都可以添加附件。
  • Word、Excel、PPT 会自动转一份文字版，所有队友都能读；点"预览"可以直接看，PDF 也可以。
  • 队友做出来的图片、视频、文件会显示在他的消息下面，可以放大、播放、下载，或者在文件夹里找到它。

项目

  • 左侧"项目"旁的 + 新建项目，写上项目说明（目标、背景、时间节点、要求）。项目里所有任务的队友都会看到它，还会参考同项目其他任务定下的结论。
  • 项目名旁的 + 在项目里新建任务；也可以把左侧的对话拖进项目，或点对话旁的 ⋯ → 移到项目。
  • 点任务前面的小圆圈标为完成，项目旁会显示完成进度。删除项目不会删除里面的对话。

技能库

  • 技能是可以反复用的做事方法：步骤、分工、标准、模板和踩过的坑。所有对话、所有队友共用，存在 Hola 文件夹的 data\skills 里。
  • 存为技能：团队结论右上角点"存为技能"，队友会把这次的做法提炼成一个技能；同类技能已经有的话，会合并成新版本。没有团队结论时，在右上角"技能库"里点"从当前对话整理"。
  • 自动用上：队友动手前会先看技能库，任务对得上就照着做，消息上会出现技能名，点一下能看内容。
  • 也可以自己新建，或导入现成的 SKILL.md 或技能压缩包（和 Claude Skills 格式一样）。不想让队友用某个技能时点"停用"。
  • 只导入你信得过的技能，导入后先点"编辑"看一遍。

对话、记忆和个人主页

  • 左侧"新对话"（Ctrl+N）。每个对话都有自己的聊天记录、文件夹和对话记忆，互不干扰。
  • 点右上角"对话记忆"可以查看、修改。每轮结束后会自动整理。
  • 双击左侧的对话标题可以改名。删除对话是永久删除：聊天记录、记忆、附件和产出文件一起删掉，无法恢复。
  • 点左下角你的头像打开个人主页：头像、怎么称呼你、回答要多详细、讨论风格等，所有队友都会照着来。
  • 设置 → 界面语言 / Language 可以切换中文和英文。

Hola 在后台安静运行。窗口关掉后，如果 30 分钟内没有活在跑，它会自己退出。想马上退出，点左下角"设置"→"退出 Hola"。

Union of light. Three beams of light combine into white: Claude, Codex and Gemini are equal teammates with different strengths, and you are the point in the middle, the foreman.

First time: install

  1. Install Node.js (LTS).
  2. Double-click SETUP.bat. It installs the three command-line tools, walks you through signing in to each (see the next section), and creates a Hola icon on your desktop.
  3. From then on, double-click the Hola desktop icon. No command-prompt window stays open. To recreate the icon only, double-click Create-Desktop-Icon.bat.

Mac (beta): install Node.js first, open Terminal, type bash (with a trailing space), drag SETUP.command from the mac folder into the window and press Enter. It installs the command-line tools, walks you through signing in, and creates the Hola app; open it from Launchpad or your desktop. After SETUP has run once, Login-Claude.command and the other files in the mac folder can be double-clicked and do the same as the .bat files in the table below. The Mac version hasn't been fully tested on a real Mac yet; please report problems.

Important: sign in to the command-line teammates first

Claude, Codex and Gemini, plus any teammate you add as a "command line" teammate, work through each vendor's official CLI using your own subscription. Each one must be signed in on this computer once, or it shows as offline in Hola. SETUP.bat walks you through this; to sign in again later, use these files:

TeammateSubscriptionHow to sign in
ClaudeClaude Pro / MaxDouble-click Login-Claude.bat, type /login, choose Claude account with subscription, approve in the browser, then /exit.
CodexChatGPT Plus / ProDouble-click Login-Codex.bat, choose Sign in with ChatGPT, sign in in the browser, then /exit.
GeminiGoogle AI ProDouble-click Login-Gemini.bat (it also installs the Antigravity CLI, agy), sign in with your subscribed Google account, then /quit.
Your own CLI AIWhatever it needsFollow that tool's instructions to sign in or set its key in a terminal, make sure it runs on its own, then add it to Hola.

Sign Claude in with your subscription. If Hola shows API Usage Billing, Claude is on pay-as-you-go API billing (charged separately). Open Login-Claude.bat, run /logout, then /login again.
About Gemini: since June 2026 Google no longer lets personal subscriptions use the Gemini CLI; the Antigravity CLI (agy) is required.

Missing a subscription is fine: that teammate shows as offline and the others still work. Teammates added through an API (DeepSeek and others) don't need signing in, just an API key. When a sign-in expires, its light at the top right goes dark; sign in again and click "Recheck".

Giving out work

  • No @: the working teammates answer independently, at the same time. If anyone thinks it's worth discussing, they discuss over several rounds until everyone agrees, then give you a team conclusion. The round limit and who writes the conclusion are in Settings.
  • You decide when they can't agree: with consensus, the team goes ahead and divides up the work. If they're still split at the round limit, the conclusion lists a few options and who supports each; pick one, or just type your decision in the box (no @ needed), and the team divides the work accordingly.
  • @ someone to assign it: e.g. "@Codex turn this table into Excel". With several @s, they go in @ order.
  • Hand-offs: when a teammate @s someone in a reply, the work is handed over automatically, up to 10 times in a row (changeable in Settings) so nobody loops forever.
  • Jump in or stop any time: keep sending messages while they work; "Stop" halts everyone in the conversation right away.

Adding more AIs, choosing who works

  • Teammates (bottom left) → Add teammate, in two ways:
    • API: OpenAI-compatible endpoints such as DeepSeek, Qwen, Kimi, Zhipu, OpenRouter or local Ollama. Pick a provider, enter the API key (check the provider's docs for model names), click "Save and test". Keys are stored only on this computer in data\members.json.
    • Command line: any AI with a CLI (sign it in first, see above). Enter the command and arguments; {PROMPT} in the arguments is replaced with the task.
  • API teammates can't read or write files or go online; they think and write, and text attachments you send are included for them.
  • Edit what each teammate is good at, and its colour, under Teammates → "Edit". The team divides work accordingly.
  • Models: under Teammates → "Edit" you can choose the model for Claude, Codex and Gemini, say Opus or Sonnet for Claude, and the thinking effort (deeper thinking gives better answers but is slower and uses more quota); "Default" uses the tool's own setting. Picking a model your subscription doesn't include will fail; just switch back to "Default".
  • Usage: each reply shows the model it used and its usage (input / output tokens; hover for details), and the teammate status at the top right shows this conversation's total per teammate. On a subscription, usage counts toward your plan's quota and nothing extra is billed; on an API it's billed at the provider's price.
  • Permissions: teammates start in safe mode. Claude and Codex work only inside the chat folder, and Gemini can read but not write. To let a teammate run commands and change files anywhere on the PC, tick Full access under Teammates → "Edit"; the teammate list marks it. Only turn it on for AIs you trust, and keep backups of important files.
  • Working under the input box: click a name to leave that teammate out this time, click again to bring them back. Remembered per conversation. @-ing them directly still brings them in.

Images and files

  • Use the paperclip, drag files into the window, or paste a screenshot with Ctrl+V.
  • Word, Excel and PowerPoint files get an automatic text version every teammate can read. Click "Preview" to view them, and PDFs too.
  • Images, videos and files your teammates make appear under their message: enlarge, play, download, or show them in the folder.

Projects

  • Click + next to "Projects" on the left to create one, and write a brief (goal, background, deadlines, requirements). Teammates on every task in the project see it, and take into account what the project's other tasks decided.
  • The + next to a project name adds a task to it. You can also drag a chat into a project, or use ⋯ → Move to project.
  • Click the circle in front of a task to mark it done; the project shows its progress. Deleting a project doesn't delete its chats.

Skill library

  • A skill is a reusable way of getting something done: steps, who does what, standards, templates and lessons learned. Every chat and every teammate shares the library, stored in data\skills in the Hola folder.
  • Save as skill: click "Save as skill" at the top right of a team conclusion and a teammate writes up how the team did it. If a similar skill already exists, it's merged into a new version. Without a team conclusion, open "Skills" at the top right and click "From this chat".
  • Used automatically: before starting, teammates check the library and follow any skill that fits. The message shows the skill's name; click it to read it.
  • You can also write one with New skill, or Import an existing SKILL.md or skill zip (same format as Claude Skills). Click "Disable" to keep teammates from using a skill.
  • Only import skills you trust, and click "Edit" to read one after importing.

Conversations, memory and your profile

  • "New chat" on the left (Ctrl+N). Each conversation has its own history, folder and memory, kept separate.
  • "Memory" at the top right lets you view and edit it. It's updated automatically after each round.
  • Double-click a conversation title to rename it. Deleting a conversation is permanent: history, memory, attachments and output files are all removed.
  • Click your avatar at the bottom left for your profile: avatar, what to call you, how detailed answers should be, discussion style and more. Every teammate follows it.
  • Settings → 界面语言 / Language switches between Chinese and English.

Hola runs quietly in the background. After you close the window, it exits on its own if nothing has run for 30 minutes. To quit right away: "Settings" → "Quit Hola".

FAQ

Some of the lights at the top right are dark
That teammate isn't connected. Click to see why; usually the CLI isn't installed or the sign-in expired. Sign in again with the matching file from the table above, then click "Recheck".
Claude shows API Usage Billing
It isn't signed in with a subscription. Double-click Login-Claude.bat, run /logout, then /login and choose the subscription account.
Nothing happens when I double-click the icon
Double-click START.bat to see a window with the error, take a screenshot and ask in Issues.
I want to try it without signing in to anything
Double-click START-DEMO.bat and open http://localhost:3457. The teammates act out the whole flow from a script.
